# Python 练习与验收

## 基础练习（P0）

1. 输入一组 JD 技能词，统计词频并按次数降序输出。
2. 读取 JSON 配置，缺少 `model` 时给出清晰错误。
3. 定义 `StudyTask` Pydantic 模型：标题、优先级、预计小时、是否完成。
4. 将任务列表保存为 UTF-8 JSON，再读取并计算总小时。
5. 写异步函数模拟三个模型请求，比较串行与并发耗时。
