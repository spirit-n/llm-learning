# 00｜学习规划

## 推荐使用方式

1. 先读 [8周倒排计划](./8周倒排计划.md) 或 [10周求职倒排计划](./10周求职倒排计划.md)，把任务复制到自己的日历；零基础大模型经验者优先选 10 周版。
2. 非科班先读 [零基础学习方法](./零基础学习方法.md) 和 [基础术语表](./基础术语表.md)。
3. 用 [能力矩阵](./能力矩阵.md) 每周日自评，只看证据，不凭感觉打分。
4. 学每章时按“概念 → 最小 Demo → 失败实验 → 项目整合 → 面试复述”完成闭环。
5. 资料统一从 [资源导航](./资源导航.md) 进入，优先官方文档。
6. 微软课程按 [三套 Beginner 教程总导读](./微软Beginner教程总导读.md) 穿插学习，不要连续通刷三个仓库。
7. 其他教程从 [章节配套教程索引](./章节配套教程索引.md) 按薄弱点选，每章最多一个主教程、一个补充教程。

## 优先级

| 等级 | 内容 | 完成标准 |
|---|---|---|
| P0 必须 | Python 应用基础、RAG、Function Calling、LangGraph、MCP、评测、部署 | 能独立实现并解释取舍 |
| P1 重要 | LangChain、Context、Skills、Harness、AgentScope | 能做 Demo，并与替代方案比较 |
| P2 岗位相关 | A2A、微调、Transformer、多模态 RAG、GraphRAG | 能讲 3～5 分钟并完成选定实验 |
| P3 技术雷达 | Dify、Coze、从零预训练、复杂多 Agent、前沿协议 | 理解定位、成熟度、适用边界，按 JD 深挖 |

## 每周时间配比（20～30 小时）

- 40%：项目编码与测试（8～12 小时）
- 20%：官方文档和概念笔记（4～6 小时）
- 15%：评测、失败分析与重构（3～4.5 小时）
- 10%：扩展主题/P2～P3 技术雷达（2～3 小时）
- 15%：面试表达、岗位搜索、投递与复盘（3～4.5 小时）
