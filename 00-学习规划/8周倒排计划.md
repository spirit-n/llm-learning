# 8 周倒排计划

计划按每周 6 个主学习日设计，每天约 3～4 小时；第 7 天安排 2～6 小时项目冲刺、求职复盘或休息，总投入 20～30 小时。每天列出的任务是主线，完成后继续本周的“扩展池”。

## 第 1 周：从后端工程师切入 LLM 应用

**目标：** 不追求 Python 全面熟练，先能写可靠的 LLM 服务和工具调用。真实模型只做一次最小连通性验证；工具循环先用假模型写测试，避免 API Key、余额或网络问题阻塞学习。

- Day 1：安装 Anaconda/VS Code，创建 conda 环境，安装 Jupyter/ipykernel，运行入门 Notebook。
- Day 2：Python 类型、容器、函数、异常、模块、Pydantic；做 Java/Python 语法对照笔记。
- Day 3：FastAPI、async/await、httpx；完成 `/health` 与 `/chat`。有 API Key 时调用一次真实模型；没有时先返回固定/假模型响应。
- Day 4：Prompt、消息角色、temperature、token、结构化输出。
- Day 5：Function Calling；先用可预测的假模型实现计算器、指标定义、只读查询三个工具的完整循环。
- Day 6：加入参数校验、超时、重试、token/耗时日志和测试；测试通过后再选一个真实模型供应商接入，不同时申请多个平台。

**验收：** API 能稳定返回结构化结果；非法工具参数被拒绝；README 能解释“模型决定调用什么，程序决定是否执行”。

**求职：** 收集 30 个目标 JD，按 RAG、Agent、Python、部署、模型基础等标签统计频次。

**扩展池（P2）：** `uv`/`pyproject.toml`、asyncio 并发控制、provider adapter、streaming、结构化日志、prompt injection 基础。

**微软教材：** LangChain for Beginners 的 00～04 章；只运行模型、消息、结构化输出和 Tool 的最小示例。

## 第 2 周：RAG 基线

- Day 1：理解 RAG 的 ingest、index、retrieve、generate 四段链路。
- Day 2：解析 Markdown/PDF，处理标题、页眉页脚、表格和元数据。
- Day 3：固定、递归、标题、语义 chunk 对照实验。
- Day 4：embedding、相似度、top-k、向量库；跑通 Qdrant。
- Day 5：生成带引用答案；实现“证据不足就拒答”。
- Day 6：人工制作 20 条问题、答案和证据 chunk。

**验收：** 能指出一次错误属于解析、切分、召回、排序、上下文还是生成问题。

**扩展池（P1/P2）：** parent-child、query rewrite、HyDE、metadata filtering、PDF 表格/图片解析。

**微软教材：** LangChain 第 07 章 Documents/Embeddings/Semantic Search；把示例接入自己的 10～50 篇公开文档。

**真实模型检查点：** 如果第 1 周只用了假模型，本周在生成环节接入一个真实供应商；provider 不可用时，检索、切分和评测仍可独立继续。

## 第 3 周：RAG 进阶与评测

- Day 1：BM25 与 dense retrieval 的互补性。
- Day 2：hybrid search、RRF、去重与 metadata filter。
- Day 3：cross-encoder/late-interaction reranker；分析召回率和延迟。
- Day 4：RAGAS 指标；补齐 30～50 条 golden set。
- Day 5：对照 baseline、hybrid、hybrid+rerank，记录 Recall@k、MRR、faithfulness、延迟与成本。
- Day 6：完成项目一 README、架构图、失败案例和演示。

**模型概念卡（P2，60～90 分钟）：** 阅读 [Transformer 通俗但准确的解释](../14-模型基础与微调/01-Transformer详解.md)，只掌握 token、embedding、attention、上下文窗口和 decoder-only 如何影响 RAG；公式推导留到求职方向需要时再补。

**求职：** 写出项目一两版描述：100 字简历版和 3 分钟面试版。

**扩展池（P2/P3）：** multimodal RAG、GraphRAG、Corrective/Self/Adaptive RAG，只选择一个做最小对照实验，其余形成技术卡片。

**微软教材：** 暂不进入 Agentic RAG；先用本周评测证明固定 RAG 的召回和生成基线。

## 第 4 周：LangChain 与 LangGraph Agent

- Day 1：只学 LangChain 当前核心抽象：model、message、tool、retriever、middleware、agent。
- Day 2：不用框架手写一个有限步数的 tool loop，再用 LangChain 重写并比较。
- Day 3：LangGraph 的 State、Node、Edge、Conditional Edge。
- Day 4：ToolNode、循环、错误路由、最大步数和确定性节点。
- Day 5：checkpoint、持久化、Human-in-the-loop、interrupt/resume。
- Day 6：完成指标查询 Agent：schema 检索 → SQL 生成 → guard → 执行 → 校验 → 回答。

**模型概念卡（P2，60～90 分钟）：** 阅读 [微调、LoRA 与实验流程](../14-模型基础与微调/02-微调流程详解.md)，能说明预训练、SFT、LoRA/QLoRA，以及为什么动态知识和引用需求通常先选 RAG。

**求职：** 开始投递。先投 10～15 个匹配度 60%～80% 的岗位，以真实反馈校准路线。

**扩展池（P1/P2）：** subgraph、并行节点、长期记忆、time travel、状态迁移与 property-based test。

**微软教材：** LangChain 第 05 章 Agents；AI Agents 的 Intro、Design Patterns、Tool Use、Planning。将模式映射为 LangGraph 状态图。

## 第 5 周：框架对照、Context、Skills 与 Docker 基础

- Day 1：用 0.5～1 天完成 AgentScope ReAct Agent、一个 Tool 和一个 routing；与 LangGraph 比较抽象、控制流和状态恢复，不再展开第二套完整框架主线。
- Day 2：Context 分层、选择、压缩、隔离、刷新和预算。
- Day 3：长工具输出摘要、历史裁剪、schema 按需检索。
- Day 4：按 Agent Skills 规范制作 `clickhouse-sql-review` skill。
- Day 5：主要用 LangGraph 做单 Agent 与多 Agent 对照；回答“为什么多数场景先用单 Agent”，AgentScope 复刻为可选项。
- Day 6：Docker 基础：image、container、Dockerfile、端口和环境变量；把 FastAPI `/health` 装进镜像运行。

**求职：** 每周投 15～25 个岗位；记录每个岗位缺口，不因单个 JD 临时改完整路线。

**扩展池（P2/P3）：** AgentScope Studio、实时 Agent、A2A Agent、长期记忆评测、多 Agent 辩论的收益/退化实验、Docker volume/network。

**微软教材：** LangChain 第 08 章 Agentic RAG；AI Agents 的 Agentic RAG、Multi-Agent、Context、Memory。必须做固定/Agentic 与单/多 Agent 对照。

## 第 6 周：MCP 与 Harness（A2A 概念）

- Day 1：MCP Host/Client/Server、tools/resources/prompts、能力协商。
- Day 2：实现 stdio MCP Server：list_tables、describe_table、run_readonly_sql。
- Day 3：再实现 Streamable HTTP；加入鉴权、超时、白名单、limit、审计。
- Day 4：MCP 与 Function Calling 的边界；用 1～2 小时制作 A2A 概念卡，只掌握 Agent Card、Message、Task、Artifact 和与 MCP 的区别。
- Day 5：Harness：task spec、context builder、tool registry、guard、executor、verifier、trace、recovery。
- Day 6：将 MCP 接入 LangGraph Agent，演练失败、重试、人工确认和恢复。

**求职：** 第一次完整模拟面试，录音并复盘表达过长、概念混淆和无数据支撑的问题。

**扩展池：** P1 做 remote MCP 认证、OAuth 思路、MCP 安全攻击面和工具版本兼容；A2A 最小服务降为 P3，只有相关 JD 明确要求时再做。

**微软教材：** LangChain 第 06 章 MCP；MCP for Beginners 的 00～03、First Server/Client、stdio、Testing、Inspector、Auth；AI Agents 的 Protocols、Trustworthy、Security。

## 第 7 周：生产化与可观测性

- Day 1：组件级、轨迹级、端到端评测；tool call accuracy 与 goal success。
- Day 2：trace、结构化日志、request/task/tool_call ID。
- Day 3：在第 5 周 Docker 基础上完成 Compose、配置分层、健康检查、依赖锁定和可复现构建。
- Day 4：鉴权、限流、超时、重试、幂等、敏感信息脱敏。
- Day 5：缓存、并发、token/成本统计、模型降级。
- Day 6：部署项目，跑 eval v2，并整理优化前后数据。

**求职：** 更新简历和项目链接；集中投递；准备系统设计题。

**扩展池（P1/P2）：** OpenTelemetry、队列化长任务、模型路由/降级、缓存语义、红队测试和故障注入。

**微软教材：** MCP Practical/Best Practices/Tooling；AI Agents 的 Production。课程内容转成项目部署和故障清单。

## 第 8 周：作品集与面试冲刺

- Day 1：复习第 3 周概念卡，把 Transformer、attention、embedding、decoder-only 压缩成 5 分钟面试版本。
- Day 2：复习第 4 周概念卡，把 SFT、LoRA/QLoRA、数据、评测、部署和 RAG/微调选择整理成面试答案。
- Day 3：RAG 高频题与白板架构。
- Day 4：Agent、MCP、Context、Harness、评测与安全高频题。
- Day 5：给三个项目录制 3～5 分钟演示，检查 README 可复现性。
- Day 6：模拟面试、修改答案、形成下一轮补缺计划。

**最终门槛：** 陌生面试官只看仓库 README，也能在 10 分钟内理解问题、设计、指标、取舍和你的贡献。

**扩展池（P2/P3）：** LoRA/QLoRA 最小实验、本地推理与量化、Dify/Coze 工作流对照、Computer Use、Agentic RL 等前沿主题卡片。

**微软教材：** 只补未掌握的 P0/P1 章节；Browser Use、Microsoft Agent Framework、MCP advanced 等按 JD 选修，不追求打卡全套。
