# 章节配套教程索引

核验日期：2026-07-11。这里不是“收藏夹”，而是每章最多选择 1 个主教程、1 个补充教程。先完成本仓库中文笔记，再打开外部资料。

## 00～03：基础、LLM 与工具调用

| 对应章节 | 教程 | 为什么推荐 | 怎么学/何时停 |
|---|---|---|---|
| 00/01 Python | [Microsoft Python for Beginners](https://github.com/microsoft/c9-python-getting-started/tree/master/python-for-beginners) | 微软的入门材料，适合非科班补变量、条件、循环、函数等 | 本仓库 Notebook 跑通后选薄弱主题；不需要完整通刷旧视频/API |
| 00/基础 AI | [Microsoft AI for Beginners](https://github.com/microsoft/AI-For-Beginners) | 传统 AI/ML 的系统背景课 | P3；只有 Transformer/ML 基础明显不足且时间充足时选看 |
| 02 LLM/Prompt | [Microsoft Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) | 21 课覆盖生成式 AI、Prompt、RAG、Function Calling、安全等 | 先看概念/Prompt 相关课程；代码若依赖 Azure 可只做阅读 |
| 02 Prompt | [Anthropic Prompt Engineering](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview) | 官方方法强调先定义成功标准和评测，再优化 Prompt | 只读当前实验需要的 best practice；每个技巧必须用 20 条样本验证 |
| 03 Tool Calling | [Hugging Face Agents：Actions](https://huggingface.co/learn/agents-course/en/unit1/actions) | 用 stop/parse、JSON/函数调用解释模型文本如何变成外部动作 | 读完后画“模型提出→程序解析→验证→执行→Observation”的流程 |
| 03 Tool Calling | [Microsoft AI Agents：Tool Use](https://github.com/microsoft/ai-agents-for-beginners/tree/main/04-tool-use) | 给出 schema、执行、消息、集成、错误和状态等完整构件 | 与本仓库手写 loop 对照；微软云代码不必全部运行 |

## 筛选规则

1. 优先官方 docs、官方课程、原始仓库；二手视频只补中文直觉。
2. 一个主题同时出现多个框架时，先理解流程，再选一个实现。
3. 课程代码能运行不等于项目可靠；必须加入失败、权限、评测和成本。
4. 遇到付费/云账号依赖，先完成概念和 fake/local 实验，不为打卡盲目消费。
5. 每月复查一次链接与版本，失效/过时资源标注日期而非默默替换。
