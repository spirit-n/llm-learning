## 使用视频的规则

- 先看官方 quickstart，再用视频补直觉；不要反过来。
- 出现 `LLMChain`、旧版 agent executor、旧 memory API 或 SSE-only MCP 教程时，先查当前文档是否已变化。
- 不下载来历不明的“就业资料包”，不要把视频播放时长当成学习进度。
- 每段视频最多记三类内容：关键概念、设计取舍、一个可验证实验。
