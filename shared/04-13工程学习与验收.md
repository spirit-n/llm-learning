## 运行方式

进入对应工程目录后：

```powershell
python -m pip install -e ".[dev,live]"
python -m pytest -q
```

demo 的模块名及详细阅读顺序见各工程 README。模型连接使用 [统一配置](README.md)，显式运行：

```powershell
python -m pytest -q tests_live -m live
```
