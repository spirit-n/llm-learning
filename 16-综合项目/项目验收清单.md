# 项目验收清单

## 可复现

- [ ] README 写明 Python/依赖版本和启动命令
- [ ] `.env.example` 只有变量名和说明，无密钥
- [ ] 有 fake provider / mock tool，评审者无需付费 API 也能跑核心测试
- [ ] 数据来源和许可证明确，无公司机密
- [ ] 单元测试、集成测试、smoke test 可运行

## 设计质量

- [ ] 架构图与实际代码一致
- [ ] LLM 节点与确定性节点边界清楚
- [ ] 每个循环有最大步数和退出路径
- [ ] 状态、prompt、context、tool、模型、数据集有版本信息
- [ ] 权限在数据访问层生效，不只靠 prompt

## 评测与观测

- [ ] 有 baseline，不只展示最终版本
- [ ] golden set 覆盖正常、边界、拒答、对抗、越权
- [ ] 报告包含分组指标和失败样本
- [ ] trace 能定位模型、检索、工具、业务逻辑问题
- [ ] 同时报告质量、延迟、成本与安全指标

## 求职呈现

- [ ] README 首屏有一句话、架构图、结果表、Demo
- [ ] 简历描述不使用无法证明的“显著提升”
- [ ] 能在 3 分钟和 10 分钟两个时长讲项目
- [ ] 能回答三个失败案例和三个技术取舍
- [ ] 演示包含一次受控失败，不只展示 happy path
